Your job is to create a wiring diagram in the PlantUML Deployment Diagram format using the elk layout engine to represent all the wiring in the ISMS instrument. Use the file "Blocks.csv" for the blocks colored as specified in the Block color column and organized into groupings and subgroups (specified in the group column) use the "package" block for groupings and the "rectangle" block for components. Layout should be from top to bottom: topside, external components (outside of a grouping), main housing. Connectors should be represented as "hexagon" blocks with each connector pin as a numbered circle within the connector block for the connectors with specified PIN numbers. Use the file "wire_links_with_pins.csv" for the connection edges.
