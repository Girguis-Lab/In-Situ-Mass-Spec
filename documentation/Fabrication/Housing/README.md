
# Housing Assembly

### Install Rear End Cap

1. Wipe away debris and old grease from sealing surfaces with a lint-free cloth.

2. Use Molykote 111 silicone grease to lightly grease the o-rings for the end cap (o-ring dash sizes #261 and #359) and install them in the grooves:<br/>
![O-Ring Placement](<./Images/End-Cap O-Rings.png>)

3. Hold the endcap up against the main enclosure<br/>
![alt text](<Images/Rear Endcap Install.png>)

3.  Expand the black housing clamp slightly and install over the flange clamp protrusions, then install the hose clamp over that and tighten.

### Front Endcap Install

1. Unscrew the vent plug from the end cap using a hex key:<br/>
![Vent Plug](<./Images/Vent Plug.png>)

4. Slide chassis assembly along with main endcap into tube, making sure the rails don’t scratch the inner surfaces of the housing.<br/>
![Clamp Ring Sled Install](<./Images/Clamp Ring Sled Install.png>)

5. Add large desiccant packs to absorb the water vapor that will be ejected from the vacuum pumps into the housing as you go anywhere they will fit.

6. Turn the whole ISMS enclosure vertically onto the flat opposite end cap.

7. Press down firmly, making sure the face o-ring stays centered in its groove as it goes \- extra grease on that side may help keep it in the groove.

8. Expand the black housing clamp slightly and install over the flange clamp protrusions, then install the hose clamp over that and tighten: <br/>
![Housing Closed ](<./Images/End Cap Closed.png>)
