# ISMS V3 Internal PCB build guide

The ISMS v3 internal PCB was designed and assembled by Acbotics Research.

They are the best source of answers about this build.

### Useful files:

##### Bill of materials

electronic parts needed to assemble the board (BOM: Bill of materials):

[100818_v1.0.1_BOM_Std.csv](<mass spec board v1.0.1/assembly/100818_v1.0.1_BOM_Std.csv>)

##### Electrical Schematic

Schematic with notes in green - taken while going through board schematic with Actbotics staff.

 [100818_v1.0.1_Schematic_WITH_NOTES.pdf](<mass spec board v1.0.1/100818_v1.0.1_Schematic_WITH_NOTES.pdf>)

**Assembly Drawing**

Shows where the final components will be layed out.

 [100818_v1.0.1_Assembly.pdf](<mass spec board v1.0.1/100818_v1.0.1_Assembly.pdf>)

##### Gerber Files

Used by PCB Factories to create the various layers in the PCB stackup. The zip file  [100818_v1.0.1_FAB.zip](<mass spec board v1.0.1/100818_v1.0.1_FAB.zip) is what you would give to a PCB house to have this board created.

##### Pick 'n Place files

Given to an automatic assembly service that will place and solder all the components onto the board by machine (Eg. PCBway PCBA)  [100818_v1.0.1_PnP_Std_TOP.csv ](<mass spec board v1.0.1/assembly/100818_v1.0.1_PnP_Std_TOP.csv) (top side) & [100818_v1.0.1_PnP_Std_BOT.csv](<mass spec board v1.0.1/assembly/100818_v1.0.1_PnP_Std_BOT.csv) (Bottom Side>)

#### Changes from as designed

See [100818 Rework.docx](<PCB commisioning and functionality testing Documentation from Acbotics Research/100818 Rework.docx>)

Also connectors could be redesigned to accommodate the Fwd/Rev fluid pump 5v output signal in a shared connector with the other fluid pump pins.
